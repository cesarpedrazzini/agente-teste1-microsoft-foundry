# Agente-Teste1 — Microsoft Foundry

## Objetivo
Projeto experimental para aprender a criar, configurar e testar agentes de IA usando o Microsoft Foundry.

## Ambiente
- Plataforma: Microsoft Foundry
- Projeto: `proj-foundry-pedrazzini`
- Agente: `Agente-Teste1`
- Versão observada: 2

## Configuração do agente
Consultar o arquivo `instrucoes-agente.md`.

## Modelo e ferramentas
Consultar o arquivo `configuracao.md`.

## O que aprendi
- Criação e configuração de agentes de IA.
- Seleção e utilização de modelos.
- Testes de conversação e avaliação de respostas.
- Organização e documentação de projetos técnicos.

## Observações
Este repositório documenta o projeto de aprendizagem. Ele não contém uma cópia automática dos recursos hospedados no Azure.

As configurações e os recursos deverão ser recriados no Microsoft Foundry para executar o agente novamente.

## Segurança
Não armazenar chaves, senhas, tokens ou credenciais neste repositório.
